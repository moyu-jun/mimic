Mimic

v0.1.0
Windows 按键与鼠标模拟工具

📖 产品概述

Mimic 是一款专为 Windows 平台设计的桌面按键/鼠标模拟工具，主要用于游戏场景中的自动化操作。通过配置按键序列、鼠标点击坐标与全局热键，按下启动热键后即可在后台循环执行模拟，支持热键提示音与自定义提示音录制。

核心特性：
  • 硬件级按键/鼠标模拟（基于 Interception 驱动）
  • 全局热键控制，支持在游戏中启动/停止
  • 支持按键按下、长按、组合键模拟
  • 支持鼠标左键、右键、中键点击及坐标拾取
  • 可录制自定义热键提示音（最长 5 秒）
  • 配置自动保存，重启后自动恢复

💻 系统要求

  • 操作系统：Windows 10 / 11（仅支持 Windows）
  • 权限要求：安装/卸载驱动需要管理员权限
  • 依赖驱动：Interception 驱动（首次使用需安装并重启系统）
  • 麦克风：录制自定义提示音时需要（可选）
⚠️ 重要提示：应用启动不需要管理员权限，仅在安装/卸载驱动时需要。首次使用时若未安装驱动，在首页会提示「驱动未安装」，点击「安装驱动」按钮会引导您提权。

🚀 快速开始

第一步：安装 Interception 驱动

  1. 打开 Mimic，在首页查看驱动状态
  2. 若显示「驱动未安装」，点击「以管理员身份重启」按钮（弹出 UAC 提示，点击「是」）
  3. 应用以管理员身份重启后，点击「安装驱动」按钮
  4. 安装成功后，点击「重启电脑」按钮重启系统（驱动需重启后才会加载）
  5. 重启后再次打开 Mimic，首页驱动状态应显示「Interception 驱动已加载」（绿色指示灯）
💡 提示：驱动安装是一次性操作，安装成功并重启后，后续使用无需管理员权限，也无需重复安装。

第二步：配置按键模拟（示例：自动按 F 键）

  1. 点击左侧菜单的「按键模拟」页
  2. 点击顶部的输入框，按下键盘上的 F 键进行捕获
  3. 点击「添加」按钮，列表中出现一行「F | 20 ms」
  4. 勾选该行最左侧的复选框启用该动作
  5. 修改时间间隔为 1000（即每秒按一次 F）

第三步：启动模拟

  1. 确认左侧菜单高亮在「按键模拟」页
  2. 按下默认启动热键 F12（或在「设置」页自定义的热键）
  3. 听到提示音后，模拟开始运行，底部状态栏显示「按键模拟运行中」
  4. 再次按下 F12 停止模拟，听到停止提示音
⚠️ 注意：热键仅在「按键模拟」或「鼠标模拟」页有效。在首页或设置页按热键不会触发模拟。

⚙️ 功能详解

🏠 首页（状态仪表盘）

显示应用当前状态，包括：

  • 管理员权限：绿色勾号表示已授权，橙色感叹号表示未授权（需安装/卸载驱动时提权）
  • 驱动状态：绿点=已加载，橙点=已安装待重启，灰点=未安装
  • 当前热键：显示启动/停止热键，点击「设置」页可修改

⌨️ 按键模拟页

配置需要模拟的按键序列：

  • 添加按键：点击顶部输入框，按下目标键，点击「添加」
  • 启用/禁用：勾选复选框启用，取消勾选禁用（禁用的动作不会执行）
  • 时间间隔：每个动作执行后等待的时间（毫秒），默认 20ms
  • 删除按键：点击行末的 ✕ 按钮删除该动作

执行逻辑：循环执行所有已启用的动作，每个动作执行后等待对应的时间间隔，然后执行下一个。

🖱️ 鼠标模拟页

配置需要模拟的鼠标点击位置：

  • 添加动作：点击底部「添加」按钮新增一行
  • 坐标拾取：点击「坐标拾取」按钮，窗口隐藏，在目标位置单击鼠标左键拾取坐标
  • 时间间隔：每个动作执行后等待的时间（毫秒），默认 20ms
  • 删除动作：点击行末的 ✕ 按钮删除该行

执行逻辑：循环点击所有已配置坐标的动作（默认左键点击）。

🎛️ 设置页

自定义全局热键与提示音：

  • 启动热键：点击输入框捕获新按键，点击「保存」应用
  • 停止热键：点击输入框捕获新按键，点击「保存」应用（可与启动热键相同）
  • 提示音录制：
    • 点击「录制」展开录制面板
    • 点击「开始录制」对着麦克风说话（最长 5 秒）
    • 点击「结束录制」或等待 5 秒自动停止
    • 拖动波形上的起始/结束标记调整剪裁范围（最短 100ms）
    • 点击「试听」预览选区，点击「保存」覆盖原文件

❓ 常见问题

Q1: 为什么按热键没有反应？

可能原因：

  • 当前页面不是「按键模拟」或「鼠标模拟」页（热键仅在这两个页面有效）
  • 驱动未安装或未重启系统（首页检查驱动状态）
  • 配置中没有已启用的动作（检查复选框是否勾选）

Q2: 安装驱动后提示「已安装需重启系统」？

解答：Interception 驱动是内核级驱动，安装后必须重启系统才会加载到内核。重启前驱动处于「已安装但未生效」状态，热键功能不可用。请点击「重启电脑」按钮或手动重启。

Q3: 如何卸载驱动？

步骤：

  1. 在首页点击「以管理员身份重启」按钮提权（若已是管理员权限则跳过）
  2. 驱动卡片右侧点击「卸载驱动」按钮
  3. 在展开的确认区输入 卸载驱动 四个字，点击「确认卸载」
  4. 卸载成功后点击「重启电脑」按钮重启系统（卸载也需要重启才彻底生效）

Q4: 录制提示音时提示「未检测到麦克风」？

解答：系统未检测到默认输入设备。请检查：

  • 麦克风是否已连接并设为 Windows 默认录音设备（设置 → 系统 → 声音）
  • 麦克风是否被其他应用占用

Q5: 模拟运行中如何修改配置？

解答：模拟运行期间界面会锁定（半透明遮罩），无法修改配置。需先按停止热键停止模拟，再修改。这是为了防止运行中修改导致行为不一致。

Q6: 配置保存在哪里？

解答：配置文件为 mimic.ini，保存在 exe 同级目录。每次修改配置后自动保存，下次启动自动加载。若配置文件损坏或缺失，应用会自动创建默认配置。

⚠️ 注意事项

🚨 安全警告：
  • Interception 是内核级驱动，安装/卸载需要管理员权限，且需重启系统
  • 卸载驱动前请确认模拟已停止，避免运行中卸载导致系统不稳定
  • 请仅从官方渠道获取安装程序，避免使用来源不明的驱动文件
⚠️ 使用建议：
  • 按键模拟的时间间隔建议不低于 10ms，过短可能导致游戏检测异常
  • 热键建议设为 F12 等功能键，避免与游戏内快捷键冲突
  • 录制提示音时环境请保持安静，避免背景噪音
  • 首次使用建议在测试环境（如记事本）验证功能正常后再用于游戏
💡 性能提示：
  • 模拟运行时应用处于后台循环执行状态，CPU 占用取决于动作数量与时间间隔
  • 建议时间间隔不低于 20ms（即每秒不超过 50 次操作），保持系统流畅
  • 提示音播放通过 Windows waveOut API，延迟 < 15ms，不影响模拟精度

🔧 技术说明

底层实现

  • 模拟驱动：Interception（第三方开源内核驱动）
  • 前端技术：Vue 3 + TypeScript + Vite
  • 后端技术：Rust + Tauri 2
  • 音频采集：cpal（Rust 跨平台音频库）
  • 运行平台：Windows 10 / 11（x64）

文件结构

  • Mimic.exe — 主程序
  • mimic.ini — 配置文件（自动生成）
  • interception.dll — 驱动通信 DLL
  • audio/按键开启.wav — 启动热键提示音（可录制覆盖）
  • audio/按键关闭.wav — 停止热键提示音（可录制覆盖）
  • drivers/install-interception.exe — 驱动安装程序
